Should I choose .SVG or .DXF for Laser Engravers and Vinyl Plotters (Cricut / Silhouette)?
Both formats are included. Select .SVG (Default) for Cricut Design Space, Adobe Illustrator, LightBurn, and Glowforge—it exports as a single unified <Compound Path> with inner holes pre-grouped. Select .DXF for industrial CAD/CAM systems (AutoCAD, SolidWorks) or if you use the free Silhouette Studio Basic Edition, which imports 1:1 millimeter .DXF files for free without requiring a paid Designer upgrade.
What uses Advanced Vision Credits vs. Unlimited CAD Exports?
All standard logo tracing, custom arched text, classical banknote hatching, slider adjustments, and 1:1 millimeter .STL, .DXF, and .SVG downloads use 0 credits and are 100% unlimited. Only clicking Advanced Vision Background Removal to strip complex photo backgrounds uses 1 credit (cached per image so moving sliders uses 0 extra credits).
